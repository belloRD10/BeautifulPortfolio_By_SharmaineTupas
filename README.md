📸 Profile Photo Upload

The portfolio includes a built-in profile-photo uploader.

How to use it

Open index.html.

Locate the profile card in the Hero section.

Click Upload Photo.

Select your image.

The selected image immediately becomes your profile picture.

Click Remove to restore the default ST placeholder.

Supported formats

JPG / JPEG

PNG

WEBP

GIF

File limit

The uploader accepts images up to 5 MB.

How persistence works

The selected image is saved using the browser's localStorage, so it can remain after refreshing the page in the same browser.

Important: The uploaded photo is stored locally in the browser. It is not uploaded to GitHub or a web server, so visitors will not automatically see a photo you selected locally.

For a permanent public profile picture, add the image to the repository and reference it from index.html.
